# Basic Python Chatbot

## 📌 Internship Task 4

A simple rule-based chatbot developed using Python. The chatbot accepts user messages and provides predefined responses based on the user's input.

## 🎯 Objective

The objective of this project is to create a basic chatbot that can understand a few predefined messages and respond appropriately.

## 🚀 Features

- Accepts user input
- Responds to greetings
- Responds to "how are you"
- Provides its name
- Explains what it can do
- Handles unknown messages
- Allows the user to exit by typing `bye`
- Runs completely in the console

## 🛠️ Technologies Used

- Python
- Functions
- `if-elif-else`
- `while` loop
- Strings
- `input()`
- `print()`

## 💬 Supported Messages

| User Input | Chatbot Response |
|---|---|
| hello | Hi! Nice to meet you. |
| hi | Hi! Nice to meet you. |
| how are you | I'm fine, thanks! How are you? |
| what is your name | I'm a simple Python chatbot. |
| what can you do | I can respond to some basic predefined messages. |
| bye | Goodbye! Have a great day! |
